เครื่องมือนี้ จำลองการทอย D16 เท่านั้น — ไม่มีขั้นตอนสร้าง seed / กระเป๋าใด ๆ ทุกครั้งที่ทอย ผล 0–F มาจากการ “กลั่น” (extract) เฉพาะแหล่งที่คุณ ติ๊กเลือก ผ่าน hash แล้วตัด 4 บิตล่างแบบไม่มี bias

1. แหล่ง entropy ที่เลือกได้

  • CSPRNG — CSPRNG ของระบบ (baseline) สม่ำเสมอ ~100% แต่ verify กระบวนการเองไม่ได้
  • Cam — thermal/shot noise ของ image sensor ผ่าน frame-diff LSB — physical noise แท้
  • Mic — Johnson-Nyquist noise ของ ADC; ปิด noiseSuppression/AGC แล้วเก็บ LSB
  • Motion — MEMS thermal + การเคลื่อนไหว ผ่าน DeviceMotion (มือถือ)

ติ๊กเลือกแหล่งไหน = แหล่งนั้นถูกนำเข้ามิกซ์; เอาติ๊กออก = หยุดใช้และตัดออกจากมิกซ์ (กล้อง/ไมค์ปิดจริง) ต้องเปิดอย่างน้อย 1 แหล่ง

2. Extractor (mixer)

roll = SHA-256( selected_sources_pool ⊕ csprng? ‖ counter ‖ hi-res-time ) value = roll[0] & 0x0F // 0–15 ไม่มี modulo bias (256 หาร 16 ลงตัว) pool ⊕= roll // hash-chain

กฎที่ค้ำความปลอดภัย: ถ้ามีอย่างน้อย 1 แหล่งที่สุ่มจริงและอิสระ ผลรวมหลัง XOR/hash ก็ยัง uniform

3. Indicator

  • Min-entropy (bits/byte) — Most-Common-Value; ใกล้ 8 ยิ่งดี
  • RCT — จับ source ค้าง/ตาย
  • APT — จับ bias ในหน้าต่าง 512 sample
  • ACTIVITY — ความแปรปรวนระยะสั้น (ใช้กับ self-test)
ขอบเขตที่ซื่อสัตย์: indicator ทั้งหมด falsify ได้ แต่ verify ไม่ได้ว่า source เป็น physical แท้ต่อ deep backdoor ⇒ เครื่องนี้คือ simulator / educational entropy สำหรับเงินจริง trust-anchor ยังคือ ลูกเต๋าจริงที่คุณเห็นตกกับตา — software เป็นได้แค่ mixer ไม่ใช่ originator
